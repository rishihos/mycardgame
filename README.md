# 10 Code Card Game

A complete, real-time online multiplayer 4-player card game.
Built with HTML5, CSS3, Vanilla JS, Node.js, Express, and Socket.IO.

## Features
- Strict Server-Authoritative Logic (No browser cheating)
- Real-time multiplayer over WebSockets
- Secret "Power Colour" (Trump) selection and delayed reveal
- Standard 52-card deck, 13 cards per player
- 10-Card Scoring system
- Reconnection support for dropped connections
- Responsive, Mobile-First Glassmorphism UI
